# Actividades de clase

- **Trade-off carousel:** equipos comparan batch vs. streaming, warehouse vs. lakehouse y dashboard vs. alerta.
- **KPI courtroom:** una persona defiende un KPI; otra cuestiona definición, fuente, sesgo y acción.
- **Architecture review:** revisión de un diagrama con foco en fallos, costos, seguridad y dependencia de proveedor.
- **Data incident drill:** investigar datos incompletos o atrasados y comunicar impacto sin ocultar incertidumbre.
- **Tool decision lab:** resolver el mismo caso con criterios explícitos para Snowflake, Power BI, Tableau y alternativas.
- **Model risk clinic:** revisar una model card buscando leakage, drift, sesgo y uso fuera de contexto.
- **Pipeline failure game:** decidir qué bloquear, qué alertar y qué rollback ejecutar cuando falla un pipeline.

Cada actividad debe cerrar con una reflexión: *¿qué nueva evidencia cambiaría nuestra decisión?*
